## Setup
### 1. Create and activate a virtual enviroment in the root of the project
```
// on Windows
python -m venv venv
source venv/scripts/activate 
```
### 2. Install dependancies
```
pip install -r requirements.txt
```
NOTE: If you are getting a Pylance import issue 'Import "_____" could not be resolved from source', make sure the right python interpreter has been selected for this project.
To do this in VScode, go to <mark>View > Command Palette > Python: select interpreter > (select the one where Django is installed aka the venv) </mark>[^1]
